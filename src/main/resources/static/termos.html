Termos de Serviço

Última atualização: 12 de novembro de 2026

1. Aceitação

Ao acessar ou usar a Indie Games API (a "API"), incluindo a documentação Swagger e a página inicial, você concorda com estes Termos. Se não concordar, não use a API.

2. Finalidade

A API é um projeto acadêmico, desenvolvido para a disciplina de Desenvolvimento de APIs com Spring Boot (TSI - SENAC). Ela serve para estudo, demonstração e avaliação, e não é um serviço comercial.

3. Dados fictícios

  • Use somente dados fictícios: nome inventado, e-mail de exemplo (como jogador@exemplo.com) e uma senha criada só para este teste.
  • Não cadastre nomes, e-mails, senhas ou qualquer dado pessoal real, seu ou de outras pessoas.
  • Os dados ficam num banco em memória (H2), podem ser vistos por quem administra a aplicação e são apagados sempre que a API reinicia.
  • A senha é armazenada como hash (BCrypt), mas isso não torna seguro usar uma senha real.

4. Uso permitido

  • Consultar, cadastrar, alterar e remover registros pelos endpoints documentados.
  • Testar a API pelo Swagger, pelo Postman ou por um front-end em uma das origens permitidas pelo CORS.
  • Estudar o código e a documentação.

5. Uso proibido

  • Tentar burlar a autenticação (X-API-Key), o limite de requisições ou qualquer outra proteção.
  • Enviar requisições automatizadas em excesso, ou qualquer forma de ataque (força bruta, injeção, negação de serviço).
  • Cadastrar conteúdo ofensivo, ilegal, discriminatório ou que viole direitos de terceiros.
  • Usar a API para guardar dados pessoais reais ou informações sensíveis.

6. Chaves de acesso (X-API-Key)

  • A chave gerada no login é pessoal. Não compartilhe a sua.
  • Um novo login substitui a chave anterior; o logout invalida a chave atual.
  • As chaves podem ser invalidadas a qualquer momento, inclusive quando a API reinicia.

7. Limites de uso

Cada IP pode fazer até 20 requisições por minuto. Acima disso, a API responde 429 Too Many Requests e informa no header Retry-After quantos segundos esperar.

8. Disponibilidade e garantias

A API é oferecida "no estado em que se encontra", sem garantia de disponibilidade, desempenho, ausência de erros ou preservação dos dados. Ela pode ficar fora do ar, ser alterada ou ser desligada sem aviso.

9. Licença e marcas

O código-fonte é distribuído sob a licença MIT. Os nomes de jogos, estúdios e plataformas usados nos dados de exemplo pertencem aos respectivos donos e aparecem apenas para fins de demonstração.

10. Alterações destes termos

Estes Termos podem ser atualizados a qualquer momento. A data no topo da página indica a versão em vigor.
